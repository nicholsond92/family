How to subscribe

  • Google Calendar: on a computer, open Google Calendar → next to "Other calendars" click + → From URL → paste the feed URL. Google refreshes subscribed feeds every few hours.
  • Outlook / Microsoft 365: Calendar → Add calendar → Subscribe from web → paste the URL.
  • iPhone / iCloud: Settings → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar → paste the URL. (On a Mac: Calendar → File → New Calendar Subscription.)

⚠️ Anyone with a feed URL can read that calendar — share the links only with family. The hub must be reachable from the internet (HTTPS) for Google/Outlook/iCloud to fetch it.
